# Flashcard Study App

## Description
A simple, beginner-friendly flashcard application to help users study efficiently.

## Features
- Create flashcards
- View flashcards
- Flip cards
- Delete cards
- Search flashcards
- Study Mode (Basic Version)
- localStorage persistence

## Technologies
- HTML
- CSS
- JavaScript
- Browser localStorage

## How to Run
Simply open `index.html` in any modern web browser.
